# LibreUniversity

Üniversiteler için özgür, denetlenebilir ve self-hosted dijital kampüs.

LibreUniversity; OBS, LMS, canlı ders, kimlik, belge, kampüs yaşamı ve raporlama süreçlerini tek tedarikçiye bağımlı olmadan, toplulukla birlikte geliştirmeyi amaçlar.

## Nereden Başlamalı?

1. [Vizyonu](https://github.com/Libre-University/docs/blob/main/VISION.md) ve [yol haritasını](https://github.com/Libre-University/docs/blob/main/ROADMAP.md) okuyun.
2. [Katkı rehberine](https://github.com/Libre-University/.github/blob/main/CONTRIBUTING.md) göz atın.
3. [`good first issue`](https://github.com/search?q=org%3ALibre-University+label%3A%22good+first+issue%22+is%3Aopen&type=issues) etiketli işlerden birini seçin.
4. Sorularınız için [Tartışmalar](https://github.com/orgs/Libre-University/discussions) bölümünü kullanın.

Kod yazmak şart değil: süreç bilgisi, dokümantasyon, test, tasarım, çeviri ve güvenlik incelemesi de katkıdır.
